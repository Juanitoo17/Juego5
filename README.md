# Juego 5: Memory

Este repositorio contiene `memory.py`, un juego de memoria en Python basado en Free Python Games. El objetivo es encontrar las parejas de un tablero de 64 casillas para descubrir la imagen del fondo.

## Cambios realizados por mí

- Agregué un contador visible de clics sobre casillas cubiertas.
- Incluí validaciones para ignorar clics fuera del tablero y sobre parejas ya encontradas.
- Implementé la detección de todas las parejas y un mensaje de juego completado con el total de clics.

## Cambios realizados por mi compañero

- Ajustó la posición de los símbolos para que aparezcan centrados en las casillas.
- Reemplazó los números por parejas de emojis como innovación del juego.

Estos cambios permiten conocer la cantidad de clics realizados y reconocer las parejas mediante elementos visuales.
